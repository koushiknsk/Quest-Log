# Quest Log

Quest Log is a gamified, habit-tracking Progressive Web App (PWA) that visualizes your daily consistency as an old-school arcade timeline. Complete daily routines to feed the pacman, maintain a streak, and build a lasting shield.

## Features

- **Arcade-style Timeline:** 30-day side-scrolling timeline where a pacman consumes completed days.
- **Protocol Management:** Define and manage daily or weekly quests and habits.
- **Shields:** Maintain streaks to earn shields, protecting your progress if you miss a day.
- **Time Machine / Simulation:** Dev tools to simulate time and verify streak/shield behavior.
- **Offline First (PWA):** Installs as a standalone app on your mobile device, storing all state locally in your browser.
